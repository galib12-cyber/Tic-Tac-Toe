# Tic Tac Toe Game

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript. This is one of my first JavaScript projects, where I tried to apply what I learned about DOM manipulation, event listeners, functions, and basic game logic.

## About the Game

Tic Tac Toe is a two-player game where players take turns marking spaces on a 3×3 grid. The first player to get three marks in a row, column, or diagonal wins the game.

If all nine boxes are filled and neither player wins, the game ends in a draw.

## Features

- Two-player gameplay (X and O).
- Automatically switches turns between players.
- Checks all possible winning combinations.
- Displays a message when a player wins.
- Detects draw situations.
- Disables the buttons after a game ends.
- Reset button to start a new game.

## Technologies Used

- **HTML5** – For the basic structure of the game.
- **CSS3** – For styling and layout.
- **JavaScript** – For game logic and interactivity.

## What I Learned

While building this project, I practiced several JavaScript concepts, including:

- Working with arrays and nested arrays.
- Using loops and conditional statements.
- Writing functions and arrow functions.

- Implementing basic game logic.
